# Story slide art

Four placeholder images (1.png – 4.png) ship here so the app builds and runs
immediately. Replace them with real illustrations whenever they're ready —
same file names, same folder, no code changes needed.

    1.png — Max's Big Bakery Order (Max staring at 4 boxes of cupcakes)
    2.png — Sophie breaks 2,314 apart by place value
    3.png — Flip the Fox shows the standard (vertical) algorithm
    4.png — Max confidently multiplies both 4×1 and 3×2-digit problems

**Recommended size: 1,980 × 630 px** (landscape, ratio ≈ 3.14 : 1) — this is
exactly 3× the `.story-image-full` desktop frame (660 × 210 px), so it stays
crisp on retina screens. Any size in that same ratio works too (e.g. the
660 × 210 px minimum, or 1,650 × 525 px used in your other Intellia SG
modules) since the frame uses `object-fit: cover` and crops automatically.
